# g9s-llm-gate

Локальный Docker-шлюз для доступа coding-агентов к нескольким LLM-провайдерам через единую точку подключения. Начальный контур — Kimi и GLM.

**Стадия проекта:** exploration. Схема маршрутизации будет определена первым шагом реализации.
