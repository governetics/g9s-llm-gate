# Seeds — Index

Навигационный индекс seed'ов — каждая запись отдельным файлом, индекс только навигация.

**Локальная специфика:** каждый seed = файл `S-NNN-<slug>.md` (slug в имени).
Политика индекса — **prune**: воплощённые (`→ D-NNN`) / дропнутые
seeds удаляются из таблицы, нумерация не переиспользуется; сами S-NNN-файлы
остаются (на них смотрят cross-ref из ADR).

**Seed** — частично зафиксированное архитектурное решение (принцип +
предварительные решения + open questions), ожидающее собственного будущего ADR.
Lifecycle: `OPEN → IN_REVIEW → CLOSED → [D-NNN]` либо `CLOSED (dropped)`.

Критерий записи (все четыре условия): (1) есть **принцип** (предварительное
решение, не тема/вопрос); (2) назван **targeted future ADR**; (3) **вне scope**
текущей сессии/ADR; (4) **load-bearing** (текущее решение опирается, либо
потеря = дорогая повторная деривация).

## Seeds vs Backlog

|  | Seeds | Backlog |
|---|---|---|
| Природа | Предварительное архитектурное решение (принцип) | Идея / feature / tech-debt |
| Связь с ADR | Targeted future ADR обязателен | Прямой связи нет |
| Использование | ADR-сессии опираются через cross-reference | Справочник; агенты сами не берут |
| Отклонимость | `CLOSED (dropped)` | Удаляется / `closed` |

Тест-разграничитель: seed = то, что способно **основать отдельную
arch/design-сессию/ADR**; не тянет → scope-extension или backlog.
